## Cell plan (Markdown vs Code)

Use this structure when authoring `.ipynb` or Markdown-rendered notebooks.

| Order | Cell type | Content |
|-------|-----------|---------|
| 1 | Markdown | Title, objectives, prerequisites |
| 2 | Markdown | Introduction |
| 3 | Markdown | Concept explanation |
| 4 | Code | Minimal illustrative example |
| 5 | Markdown | Explanation of the example |
| 6 | Code / Markdown | Exercises |
| 7 | Markdown | Summary and further practice |
| 8 | Markdown | References |
| Optional | Markdown | Instructor notes / solutions (separate or clearly marked) |
