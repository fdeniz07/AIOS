# AIOS Methodologies

This directory contains the core methodologies of the AIOS Framework.

These methodologies define how AIOS should be applied across software engineering projects.

They complement Rules, Templates, Prompts and optional Packs.

## Available Methodologies

| Methodology | File | Focus |
|-------------|------|--------|
| RDIV Workflow | [`rdiv.md`](rdiv.md) | Review → Decide → Implement → Verify |
| Architecture First | [`architecture_first.md`](architecture_first.md) | Understand structure before changing it |
| AI Collaboration | [`ai_collaboration.md`](ai_collaboration.md) | Human authority with AI assistance |
| Prompt Lifecycle | [`prompt_lifecycle.md`](prompt_lifecycle.md) | How prompts mature into library assets |
| Repository Onboarding | [`repository_onboarding.md`](repository_onboarding.md) | Starting work on an existing repository |
| Model-Agnostic AI | [`model_agnostic.md`](model_agnostic.md) | Governance independent of any single LLM |

Together, these documents define how AIOS should be applied consistently across different repositories and AI models.
